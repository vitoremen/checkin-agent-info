Política de privacidad

Este proyecto organiza información de vuelos y prepara avisos para el propietario de una única cuenta autorizada.

Datos utilizados

Se consultan los correos y adjuntos relevantes para reservas, billetes, itinerarios, cambios y cancelaciones. Las fichas privadas pueden incluir pasajero, aerolínea, vuelo, aeropuertos, fechas y zonas horarias, localizador de aerolínea, referencia de agencia y datos útiles del billete. Los datos ausentes se señalan como pendientes; no se inventan.

Dos accesos separados

El cliente OAuth propio de este proyecto utiliza el alcance gmail.readonly para diagnósticos opcionales. Ese acceso permite consultar el correo, pero no enviarlo.

Los recordatorios operativos son tareas personales de ChatGPT que utilizan, por separado, el conector de Gmail autorizado por el propietario para leer los mensajes relevantes y enviar los avisos a su propia cuenta.

Finalidad y procesamiento

Los datos se usan para identificar vuelos futuros, conservar sus cambios, buscar el localizador de la aerolínea y avisar cuando se abre el check-in aplicable a cada vuelo y billete, con información para hacerlo manualmente. Se conserva la regla oficial, sus condiciones y la fecha de verificación. No se venden ni se utilizan para publicidad.

ChatGPT procesa los mensajes consultados mediante el conector autorizado. El registro se conserva en los datos privados de las tareas personales y los avisos enviados permanecen en Gmail. Este uso está sujeto a los ajustes y condiciones de las cuentas de Google y OpenAI del propietario.

Los diagnósticos opcionales del cliente OAuth propio pueden ejecutarse localmente o en un repositorio privado de GitHub. Sus tokens se mantienen en almacenamiento privado o secretos cifrados; no deben publicarse en código, registros o artefactos. Los informes locales se conservan hasta que el propietario los elimine. Los registros técnicos deben limitarse a información agregada.

Los correos, localizadores y datos personales reales de las reservas no se incluyen en el código del repositorio ni en estas páginas públicas.

Control y eliminación

El propietario puede pausar o eliminar las tareas, revocar el conector desde los ajustes de su cuenta y retirar el acceso OAuth desde las conexiones de Google. También puede eliminar los archivos y secretos del diagnóstico. Revocar el acceso impide nuevas consultas, pero no elimina automáticamente los datos previamente guardados ni los mensajes enviados.

Políticas de Google

El uso de información recibida de las API de Google está sujeto a la Política de datos de usuario de los servicios API de Google, incluidos sus requisitos de uso limitado.

Estas páginas públicas

Son páginas estáticas alojadas en GitHub Pages, sin formularios ni analítica propia. GitHub puede tratar los datos técnicos necesarios para servirlas conforme a sus políticas. No se muestran reservas ni se solicita iniciar sesión aquí.

Responsable

El propietario del proyecto es la cuenta vitoremen. Si cambia el alcance o la finalidad del proyecto, esta política deberá actualizarse.
