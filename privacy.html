Política de privacidad

Esta política describe el funcionamiento actual de checkin-agent, una herramienta privada de uso personal del propietario de esta aplicación.

Datos y permisos

La aplicación solicita únicamente el permiso gmail.readonly. Este permiso permite leer el correo de la cuenta autorizada, incluido contenido que puede ser privado. La aplicación selecciona mensajes relacionados con viajes y puede procesar remitentes, fechas, asuntos, texto, pasajeros, trayectos, horarios y referencias de reserva presentes en esos mensajes.

También utiliza una credencial OAuth para renovar el acceso y verifica que Gmail pertenece a la cuenta configurada. No solicita permisos para enviar, modificar o eliminar correos.

Finalidad

Los datos se utilizan para identificar reservas y cambios de vuelos, detectar datos que faltan y evaluar cuándo podría realizarse el check-in. Actualmente la aplicación solo realiza lecturas y comprobaciones; el check-in está desactivado.

No se venden datos, no se usan para publicidad y no se envían correos ni reservas a modelos de inteligencia artificial para su análisis o entrenamiento.

Procesamiento y almacenamiento

Gmail proporciona los mensajes mediante su API. El procesamiento se realiza en el ordenador del propietario o en un runner temporal de GitHub Actions dentro de un repositorio privado. GitHub actúa como proveedor del entorno de ejecución; las páginas informativas públicas no reciben el contenido del correo.

La credencial se guarda localmente en una carpeta privada o como secreto cifrado de GitHub Actions. Durante la ejecución, el runner puede utilizarla para acceder a Gmail. No se publica en el código, en estas páginas ni en artifacts.

Los informes detallados locales permanecen en el equipo del propietario hasta que los elimina. En la nube, el informe detallado permanece en el runner temporal y no se sube como artifact; desaparece al finalizar el trabajo. Los logs y resúmenes de Actions contienen contadores y códigos de error, sin cuerpos de mensajes, nombres de pasajeros, referencias de reserva ni credenciales. Su conservación depende de la configuración de GitHub.

Control y revocación

El propietario puede revocar el acceso de la aplicación en las conexiones de su cuenta Google, eliminar la credencial local y el secreto de GitHub, y borrar informes y ejecuciones conservadas. Revocar el permiso detiene nuevas lecturas; no elimina por sí solo los informes locales existentes.

Uso limitado de datos Google

El uso y la transferencia de información obtenida mediante las API de Google se limitan a las funciones descritas y se ajustan a la Política de datos de usuario de los servicios API de Google, incluidos sus requisitos de uso limitado.

Visitas a estas páginas

Estas páginas estáticas no contienen formularios, rastreadores ni analítica propios. Al publicarse en GitHub Pages, el proveedor puede procesar información técnica de la visita conforme a su política de privacidad.

Contacto y cambios

La aplicación no acepta altas de terceros. Su propietario se identifica mediante la cuenta de GitHub vitoremen. Esta política deberá actualizarse antes de introducir nuevas funciones que cambien el tratamiento de datos.
